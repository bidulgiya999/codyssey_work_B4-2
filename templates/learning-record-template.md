## 4. 내 말로 평가 답변 작성

1. 메모리 증가를 전체 RAM 비율이 아니라 무엇으로 확인했는가?
2. 종료 코드만으로 원인을 확정하지 않는 이유는 무엇인가?
3. 메모리 한도를 높였는데 왜 임시 조치인가?
4. ps 평균·top 구간·앱 내부 CPU 값은 어떻게 다른가?
5. PID가 존재해도 정상이라고 할 수 없는 이유는 무엇인가?
6. 순환 락 대기와 일반 대기는 무엇으로 구분했는가?
7. 같은 143이라도 Watchdog와 수동 종료를 어떻게 구분했는가?

## 5. 설명 가능 여부

- [ ] 명령 없이도 각 명령의 목적을 말할 수 있다.
- [ ] 수치의 단위·분모·측정 기간을 말할 수 있다.
- [ ] 결론의 원본 증거를 직접 열어 제시할 수 있다.
- [ ] Before/After에서 바꾼 변수 하나와 통제 조건을 설명할 수 있다.
- [ ] 임시 조치와 근본 해결을 구분할 수 있다.
- [ ] 확인하지 않은 내용에 대해 미확인이라고 답할 수 있다.
- [ ] 예전 실험 기록과 이번 재실행 기록을 구분했다.

체크는 학습자가 직접 설명한 뒤 표시합니다. 공식 평가 점수나 합격을 보장하는 기준은 아닙니다.
